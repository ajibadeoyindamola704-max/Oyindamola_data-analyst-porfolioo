# Greenfield Academy Automated Report Card System

## Data Analytics Portfolio Project

**Tools Used:** Microsoft Excel (XLOOKUP/VLOOKUP, IF, AVERAGE, Percentage Calculations)

---

## Project Overview

The **Greenfield Academy Automated Report Card System** is an Excel-based data analytics project that automates student report card generation using a unique **Student ID**. The system replaces manual report preparation with a dynamic, formula-driven solution that retrieves student records and calculates academic performance instantly.

This project demonstrates how data analytics can improve efficiency, accuracy, and decision-making in school administration.

---

## Business Problem

Manual report card preparation often results in:

- Data entry errors.
- Incorrect calculations.
- Time-consuming report generation.
- Inconsistent student records.

The solution was to create an automated reporting system that generates accurate student report cards from a centralized dataset.

---

## Project Objectives

- Automate student report generation using **Student ID lookup**.
- Calculate **Average Score** automatically.
- Determine **Pass/Fail Status** using logical formulas.
- Calculate **Attendance Percentage** from attendance records.
- Display student academic and administrative information without manual entry.

---

## Dataset Overview

The dataset includes academic, attendance, and administrative information for each student.

| **Field** | **Description** |
|-----------|------------------|
| Student ID | Unique identifier for each student. |
| Full Name | Student's full name. |
| Grade Level | Student's class or grade. |
| Subject Scores | Scores in Mathematics, English, Science, and Social Studies. |
| Average Score | Calculated mean of subject scores. |
| Pass/Fail Status | Automatically generated academic status. |
| Days Present | Number of days attended. |
| Attendance % | Calculated attendance rate. |
| Tuition Fee | Student tuition information. |
| Class Teacher | Assigned class teacher. |

---

## Data Quality and Validation

The project improves data reliability through:

- **Formula-driven automation** to eliminate manual data entry.
- **Standardized Student IDs** for accurate record retrieval.
- **Automatic calculations** for average score, attendance percentage, and pass/fail status.
- **Consistent formatting** to reduce duplicate or mismatched records.

## Excel Functions Used

- **XLOOKUP / VLOOKUP** – Retrieve student information using Student ID.
- **AVERAGE** – Calculate average subject score.
- **IF** – Generate Pass/Fail status automatically.
- **Percentage Formula** – Calculate attendance percentage.
